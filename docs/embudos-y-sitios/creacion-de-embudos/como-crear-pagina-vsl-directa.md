## El problema
Cuando quieres llevar tráfico directo a un video de ventas (VSL) sin pedir registro previo, necesitas crear un embudo específico para ese fin, con una página que contenga el video y elementos que aparezcan después de cierto tiempo de reproducción (como un botón de compra o un formulario de contacto).

## Solución
1. Ve al apartado de **Sitios** en el panel principal.
2. Crea un nuevo embudo.
3. Crea la página dentro del embudo (la página de VSL).
4. Agrega los elementos necesarios a la página (video, textos, botones).
5. Configura los elementos que deben aparecer después de una cantidad de tiempo determinada (por ejemplo, un botón de compra que se muestra minutos después de iniciado el video).
