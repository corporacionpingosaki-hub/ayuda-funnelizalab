## El problema

El modo coexistencia permite usar la API de WhatsApp Business conectada al CRM sin perder el acceso a la app de WhatsApp Business en el celular — ambas quedan sincronizadas sobre la misma línea.

## Solución

1. Ve a **Configuración**.
2. Entra a la pestaña de **WhatsApp** e inicia el proceso para conectar una nueva línea.
3. Inicia sesión con tu cuenta de Facebook para acceder al Business Manager y crear la cuenta de WABA (WhatsApp Business Account).
4. Una vez creada la cuenta de WABA, escanea el código QR con el dispositivo móvil donde tienes instalado WhatsApp Business, para establecer la coexistencia.
5. Cuando la conexión se valide, tu WhatsApp API en coexistencia queda conectado al CRM.
