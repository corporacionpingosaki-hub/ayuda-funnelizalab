## El problema
A veces necesitas sacar tu base de datos de contactos del sistema, ya sea completa o filtrada por etiqueta u otro criterio, para respaldarla o usarla en otra herramienta.

## Solución
1. Ingresa a la pestaña de **Contactos**.
2. Selecciona los contactos que quieres exportar. Puedes seleccionarlos todos de forma masiva, o filtrar primero por etiqueta u otro criterio antes de seleccionar.
3. Con los contactos seleccionados, haz clic en los **tres puntos** (más opciones) y elige **Exportar**.
4. El sistema comenzará a exportar en formato **.csv** y generará un archivo para descargar. Si la descarga no inicia de inmediato, ve a la pestaña de **Acciones masivas**, donde podrás ver el progreso del proceso o descargar el archivo una vez esté listo.
