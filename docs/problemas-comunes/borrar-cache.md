## El problema
Cuando el CRM presenta lentitud o muestra información de forma errónea, muchas veces la causa es la caché del navegador. Borrarla y forzar una recarga suele resolver este tipo de inconvenientes.

## Solución
1. Identifica que el problema es de lentitud o carga errónea de información.
2. Dentro del CRM, en cualquier pestaña, da clic derecho y selecciona la opción **Inspeccionar**.
3. Una vez abierta la ventana de inspección, busca el ícono de actualizar dentro del navegador y dale clic derecho.
4. Selecciona la opción **Borrar caché y forzar la recarga**.
5. Verifica que la información se muestre correctamente.
