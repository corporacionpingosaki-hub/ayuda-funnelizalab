## El problema

Cuando un contacto comenta una publicación de Instagram o Facebook, o envía un mensaje directo, muchas veces nadie responde a tiempo para iniciar la conversación — esto se puede automatizar por completo.

## Solución

1. Ve al módulo de **Automatizaciones**.
2. (Recomendado) Crea o ingresa a una carpeta específica para agrupar las automatizaciones de redes sociales.
3. Crea un nuevo flujo de trabajo (workflow).
4. Configura el disparador (**trigger**): comentario en una publicación de Facebook o Instagram.
5. Agrega filtros dentro del disparador para especificar la publicación exacta o la palabra clave que debe activar el flujo.
6. Agrega una acción para **responder al comentario** — puedes cargar varias respuestas distintas, que el sistema irá usando de forma aleatoria.
7. Agrega una acción para **responder al DM** del contacto con un mensaje que inicie la conversación.
